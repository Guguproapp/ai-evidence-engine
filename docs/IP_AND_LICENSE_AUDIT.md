# AI Evidence Engine — IP and License Audit

Audit date: 2026-08-15. Scope: public repository, deployed verifier assets, C2PA/Google dependencies, and the private replacement demo video.

## Conclusion

The project source is published under Apache-2.0 and the core demo images are deterministically generated by repository code. No unlicensed commercial image or music file was identified in the tracked product assets. Final clearance is still blocked on owner attestations for the GUGUPRO name/assets, narration/audio rights, and any material used in the private YouTube upload that is not identical to the tracked local video.

## Distribution follow-up

Apache-2.0 at the repository root does not replace third-party dependency notices. Before a packaged commercial binary is distributed, generate and ship a complete third-party notices file from the final lockfiles. This does not block source-repository judging, but it remains a release obligation.
